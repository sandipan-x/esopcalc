# EsopCalc

Calculate ESOP tax in India: perquisite value taxed at your slab on exercise, plus capital gains tax on sale. Compare exercise-now vs exercise-later scenarios.

## Features
- perquisite vs capital-gains split view
- exercise-now-vs-later comparison
- income-tax slab selector
